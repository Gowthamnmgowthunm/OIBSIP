## Project Overview
AgriMaster is a responsive landing page designed for a smart farming concept.
It presents technology-based farming solutions through a clean and user-friendly interface.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design

## Features
- Sticky navigation bar
- Hero section with headline and CTA
- Crop Recommendation
- Fertilizer Guidance
- Weather Information
- About section
- Contact section
- Responsive design
- Footer

## How to Run

1. Open the project in Visual Studio Code.
2. Open `index.html`.
3. Right-click `index.html`.
4. Select "Open with Live Server".
5. The website will open in your browser.
