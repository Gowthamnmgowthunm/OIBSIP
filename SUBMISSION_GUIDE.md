# OIBSIP Submission Guide

1. Keep the GitHub repository name exactly `OIBSIP`.
2. Keep each project in its own task folder.
3. Add a README to every submitted task.
4. Capture screenshots of the working result.
5. Record a demo video.
6. Start the demo with:
   - Full Name
   - Assigned Track
   - Task Title
7. Post/link the demo on LinkedIn with `#oasisinfobyte` and relevant domain hashtags.
8. Watch at least two peer demo videos and leave substantive comments.
9. Submit the GitHub repository through the Task Submission Form when available.
10. Check the official task list for the completion threshold for your assigned track.
