## Project Overview
This project is a responsive personal portfolio website created to showcase professional information, skills, projects and contact details.

## Technologies Used
- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design

## Sections
- Home
- About Me
- Skills
- Projects
- Contact

## Features
- Sticky navigation bar
- Hero section
- Name and professional role
- Profile/avatar placeholder
- About Me section
- Skills grid
- Two project cards
- Contact information
- Smooth scrolling navigation
- Responsive design

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click `index.html`.
4. Select "Open with Live Server".
5. The portfolio will open in your browser.
