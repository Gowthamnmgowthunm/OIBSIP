## Project Overview
This project is an interactive temperature converter website that converts temperatures between Celsius, Fahrenheit and Kelvin.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Responsive Design

## Features
- Numeric temperature input
- Celsius, Fahrenheit and Kelvin selection
- Celsius conversion
- Fahrenheit conversion
- Kelvin conversion
- Real-time validation
- Absolute-zero validation
- Conversion results displayed with units
- Responsive user interface

## Conversion Examples

25 °C:
- 25.00 °C
- 77.00 °F
- 298.15 K

32 °F:
- 0.00 °C
- 32.00 °F
- 273.15 K

## How to Run

1. Open the project folder in Visual Studio Code.
2. Open `index.html`.
3. Right-click `index.html`.
4. Select "Open with Live Server".
5. Enter a temperature.
6. Select the temperature unit.
7. Click the Convert button.
