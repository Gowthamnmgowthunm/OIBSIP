# Pizza Delivery Full-Stack Application

OIBSIP Level 3 task scaffold.

## Architecture
- React frontend
- Node.js / Express backend
- MongoDB database
- Razorpay test mode for payment integration

## Required modules
- Customer and admin roles
- Pizza customization
- Cart and orders
- Payment flow
- Real-time order status
- Inventory and low-stock notifications

This folder contains the project structure and API starter. Configure environment variables before using any external service.
